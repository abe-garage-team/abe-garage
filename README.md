# Abe Garage — Garage Management System

A full-stack web application designed to help an automobile repair garage manage its daily operations.

## About the Project

Abe Garage aims to provide a centralized system for managing customers, vehicles, repair services, work orders, technicians, estimates, invoices, payments, and repair-status tracking.

This project is being developed collaboratively by a team of five.

## Planned Technology Stack

- **Frontend:** React
- **Backend:** Node.js and Express.js
- **Database:** MySQL
- **Authentication:** JSON Web Tokens (JWT) and password hashing

## Planned Features

- User authentication and role-based access
- Customer and vehicle management
- Repair services and work-order management
- Technician assignment and job-status updates
- Estimates, invoices, and payment tracking
- Public vehicle-repair status tracking
- Public website with garage information and services
